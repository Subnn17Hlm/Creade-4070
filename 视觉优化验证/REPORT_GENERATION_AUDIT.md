## 三、取证方法

1. **文件元数据**: 使用 `stat --format='%n|%s|%y'` 获取文件大小和修改时间
2. **视频验证**: 使用 `ffprobe -v error -show_entries stream=codec_name,width,height,duration` 获取流信息
3. **解码检查**: 使用 `ffmpeg -v error -i final.mp4 -f null -` 检查解码完整性
4. **黑屏检测**: 使用 `ffmpeg -v error -i final.mp4 -vf "blackdetect=d=0.5:pix_th=0.10"` 检测黑屏
5. **文案比较**: 使用 `diff` 比较原始文案与 TTS 输入文案（归一化空白后）
6. **SHA256**: 使用 `sha256sum` 计算文件哈希
7. **污染检查**: 使用 `grep` 搜索 "0.3秒出风"、"护发顺" 等污染关键词
8. **逐片段证据**: 从 `clip_records.json`、`timeline.json`、`quality_report.json` 提取
